LA DOCUMENT TYPE DESCRIPTION

Cos'è e a cosa serve?

La Document Type Description è una descrizione della grammatica di un linguaggio di markup. All'interno del file .dtd vengono specificati:

  • gli elementi ammessi;
  • gli attributi ammessi;
  • le entità.
All'interno del file .html, la dichiarazione del file .dtd può essere:
  • interna: <!DOCTYPE esempio[<!ELEMENT esempio (#nome)>]>;
  • esterna:<!DOCTYPE esempio SYSTEM "file.dtd"> .

Prendiamo come esempio la dichiarazione della D.T.D. usata nei file .html realizzati per questo sito:
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
e analizziamone i vari elementi:

  • 'html' indica che il linguaggio utilizzato è HTML;
  • 'PUBLIC' indica che il documento è definito universalmente (non localmente);
  • 'W3C' indica che il documento fa riferimento alle specifiche dettate dal W3C;
  • 'EN' indica che la D.T.D. è scritta in inglese;
  • 'Strict' indica che la D.T.D. esclude ogni elemento che riguarda il layout e non consente l'uso di alcuni elementi;
  • 'http://.../xhtml1-strict.dtd' non è altro che la URI del documento .dtd.
