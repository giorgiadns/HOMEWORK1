VALIDITÀ DI UN DOCUMENTO E DOCUMENTO WELL-FORMED

Documento well-formed

Un documento HTML si dice well-formed se rispetta le seguenti regole:

  • Gli elementi e gli attributi devono essere scritti in minuscolo;
  • Gli elementi devono essere ben nidificati;
  • Gli attributi devono essere sempre scritti tra virgolette;
  • Gli elementi devono essere sempre chiusi con un tag di chiusura o, se vuoti, tramite la chiusura abbreviata />;

Vediamo qualche esempio:

Well-formed Non well-formed
<strong>parola</strong> <STRONG>parola</STRONG>
<p>Lara <em>Croft</em></p> <p>Lara <em>Croft</p></em>
<br />, <hr /> <hr>, <br>
<th colspan="2"> <th colspan=2>

Documento valido

Un documento è valido se rispetta la grammatica di riferimento, ossia quella specificata dalla Document Type Description. Il documento deve quindi rispettare la struttura degli elementi specificata nel file .dtd e usare solo gli elementi consentiti.

Come verificare la velidità di un documento

Uno strumento utile per controllare la validità di un documento è il Markup Validation Service di W3C, dove basta caricare il file (o inserirne l'U.R.I.) per controllare tutti gli errori che rendono il file non valido.
