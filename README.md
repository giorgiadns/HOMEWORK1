IN COSA CONSISTE IL PROGETTO / COSA HO MESSO ALLA PROVA

Il progetto consiste in un minisito web fatto ad immagine e 
somiglianza di uno store di videogiochi (Epic Games Store),
in particolare della pagina di "presentazione" dei singoli giochi.
Il sito presenta il videogioco "The Shadow of the Tomb Raider" 
con le sue specifiche, l'equipaggiamento, un po' di storia 
nel caso non si conoscesse la storia del gioco e qualche curiosità.
Nella homepage è presente una lista di link, ognuno di essi 
porta ad una pagina dove viene approfondito l'argomento 
specificato nel titolo (gli argomenti sono alcuni di quelli 
elencati nella lezione 2, esercizio css-14).

La caratteristica principale messa alla prova è, come si nota
soprattutto nella homepage e nella pagina "Storia", è la creazione
di un layout a 3 colonne attraverso l'uso delle tabelle.
Sempre nella homepage, precisamente nella lista di link relativi
all'esercizio css-14, ho sperimentato l'uso dei tooltip.
Nella pagina "Equipaggiamento" ho sperimentato l'uso dei contenitori
per creare un layout a "box singolo".
